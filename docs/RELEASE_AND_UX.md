# 复刻球权限、易用性与发布方案

状态：v0.1.2-alpha 发布门槛  
更新时间：2026-09-13

## 1. 本轮要解决的问题

| 问题 | 方案 | 验收方式 |
|---|---|---|
| 首次打开不知道要授权 | 服务未开启时自动显示用途说明 | 清除应用数据后首次启动验证 |
| Android 不弹普通运行时权限框 | 明确告知无障碍属于系统设置授权，同意后跳转设置页 | 检查页面文案与跳转目标 |
| 权限说明反复打扰 | “暂不启用”后保存已展示状态 | 重启 App 不再自动弹出 |
| 用户之后找不到入口 | 首页持续显示服务状态和“去启用”按钮 | 点击可重新查看说明并前往设置 |
| 悬浮窗为何没有单独授权 | 使用 `TYPE_ACCESSIBILITY_OVERLAY`，不申请高风险的 `SYSTEM_ALERT_WINDOW` | 检查 Manifest 和实际覆盖层类型 |
| 用户担心读取内容 | `canRetrieveWindowContent=false`，不申请网络权限，说明会做/不会做什么 | Lint、Manifest 和服务配置检查 |
| 安装包难找 | README 顶部提供固定版本的一键下载按钮 | 发布后检查下载返回成功 |
| 发布容易漏测或传错版本 | GitHub Actions 自动测试、Lint、构建，标签与 App 版本不一致时拒绝发布 | 推送 main 和版本标签各跑一次工作流 |
| API 37 在公共 SDK 仓库不可复现 | compile/target 固定为公开稳定的 API 36，并使用最后兼容 API 36 的 Compose/Lifecycle 稳定版 | 本地与 GitHub runner 分别构建 |

## 2. 首次启动权限流程

```text
首次打开 App
  └─ 手势服务是否已开启？
       ├─ 是：直接进入首页
       └─ 否：自动显示权限用途说明
            ├─ 暂不启用：留在首页，并记住已展示
            └─ 同意并前往设置：打开 Android 无障碍设置
                  └─ 用户手动开启“复刻球手势服务”
                       └─ 返回 App，首页自动刷新为“已启用”
```

无障碍服务不能像相机权限一样由 App 弹出系统确认框并直接授予。App 只能先完成显著披露，再把用户带到系统设置；最终开关必须由用户操作。

## 3. 正常使用路径

1. 安装并打开复刻球。
2. 阅读权限用途说明，点击“同意并前往设置”。
3. 在系统页面找到“复刻球手势服务”并开启，然后返回 App。
4. 保持“显示悬浮球”开启，切换到要操作的 App。
5. 单击悬浮球执行默认向右滑动；拖动悬浮球可调整位置。
6. 如需停用，可在复刻球首页隐藏悬浮球，或在系统无障碍设置中关闭服务。

当前 Alpha 版的双击快捷盘、手势录制和编辑仍是后续里程碑，界面必须明确标为不可用，不让用户误以为已经完成。

## 4. 异常与恢复

- 设置页中找不到服务：确认 APK 安装完成，搜索“已安装的应用/已下载的服务”，再找“复刻球手势服务”。
- 返回后仍显示未启用：切回 App 会在 `ON_RESUME` 重新检测；仍未更新时重新进入系统设置确认开关。
- 悬浮球未出现：确认服务状态为已启用且“显示悬浮球”开关开启。
- 点击没有动作：避开锁屏、支付、密码和其他受系统保护页面；这些页面允许系统阻止覆盖层或手势。
- 不想继续授权：选择“暂不启用”，App 不会反复自动弹出；以后可从首页重新进入。

## 5. 自动化工作流

`.github/workflows/android.yml` 在以下情况运行：

- 推送到 `main`：执行单元测试、Android Lint、Debug APK 构建并保存 14 天构建产物。
- Pull Request：执行同样的质量检查，避免未验证代码进入主分支。
- 推送 `v*` 标签：先完成全部检查，再验证标签与 `versionName` 一致，最后创建 GitHub Prerelease 并上传 APK 和 SHA-256 文件。
- 手动运行：用于随时复查构建环境。

自动检查失败时不会进入发布任务。Release 使用 GitHub 提供的短期令牌，不保存额外发布密钥。

## 6. 发布门槛

发布 Alpha 前必须全部满足：

- [x] 首次启动权限说明与拒绝后不重复打扰已实现。
- [x] 首页可再次进入授权流程，返回后自动刷新状态。
- [x] 未申请网络权限和 `SYSTEM_ALERT_WINDOW`。
- [x] 无障碍服务禁止读取窗口内容。
- [x] 权限向导关键状态有自动化回归测试。
- [x] README 一键下载地址已更新到目标版本。
- [x] 本地 `testDebugUnitTest lintDebug assembleDebug` 全部通过。
- [ ] GitHub Actions 的 main 构建全部通过。
- [ ] 安装包上传完成，下载地址与 SHA-256 可访问。
- [ ] 至少一台 Android 8.0 以上真机完成首次授权、悬浮球拖动和单击滑动冒烟测试。

真机冒烟测试是稳定版发布的硬门槛；在没有真机结果时只能标记为 Alpha/Prerelease，并在发布说明中保留测试版提示。
