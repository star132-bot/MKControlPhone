# GestureDot（复刻球）产品与技术规格

状态：Draft 0.1  
更新时间：2026-09-13

## 1. 产品目标

复刻球是一款 Android 手势快捷工具。用户录制或配置一个确定性的触摸动作，随后通过悬浮球主动触发。首要场景是把频繁的滑动、点击和系统导航压缩为一次容易完成的操作。

成功标准：新用户在 60 秒内完成服务启用，并能通过悬浮球稳定执行默认“向右滑动”。

### 非目标

- 不做自主决策或 AI 代替用户操作。
- 不做抢票、刷广告、刷奖励等无人值守工具。
- 第一版不读取无障碍节点树、页面文字、密码或屏幕图像。
- 第一版不提供云同步、脚本市场、OCR 或图像识别。

## 2. 用户与场景

### 主要用户

- 大屏手机的单手用户。
- 需要反复执行固定滑动或点击的用户。
- 手部活动范围有限、难以触及屏幕边缘的用户。
- 需要快速复现固定手势的 App 测试人员。

### 关键场景

1. 阅读时单击悬浮球完成翻页。
2. 长按悬浮球并拖向动作图标，完成返回、滑动或点击。
3. 连续三击悬浮球，执行最近一次录制。
4. 在 App 内调整默认动作、快捷盘和悬浮球外观。

## 3. 交互规则

| 输入 | 默认行为 | 备注 |
|---|---|---|
| 单击 | 执行默认动作 | 多击模式下等待 280ms 判定 |
| 双击 | 打开快捷盘 | 用户可重新映射 |
| 三击 | 执行最近动作 | 第三击后立即触发 |
| 长按 | 展开环形快捷盘 | 不松手拖动，松手执行 |
| 拖动 | 移动悬浮球 | 移动超过 touch slop 后取消点击 |
| 执行中单击 | 紧急停止 | M2 实现 |

悬浮球在闲置后降低透明度，拖动结束后吸附左右屏幕边缘。系统明确禁止覆盖的页面中，允许悬浮球被隐藏，不尝试绕过系统保护。

## 4. 功能需求

### FR-01 服务引导

- 首页展示无障碍服务真实状态。
- 首次启动且服务未开启时，自动显示独立的显著权限说明。
- 用户选择“暂不启用”后记录已展示状态，后续启动不重复打扰；点击首页“去启用”仍可再次查看。
- 跳转系统设置前要求用户点击“同意并前往设置”。
- 说明必须列出服务会做什么、不会做什么，以及用户可随时撤销授权。
- 用户点击按钮进入系统无障碍设置。
- 开启权限前说明用途、访问范围和数据处理方式。
- 不把系统权限开关伪装为 App 内普通开关。

### FR-02 悬浮球

- 使用 `TYPE_ACCESSIBILITY_OVERLAY` 显示。
- 支持点击判定与拖动。
- 用户可在 App 内显示或隐藏。
- 服务重连后恢复用户设置。

### FR-03 手势执行

- 通过 `AccessibilityService.dispatchGesture()` 执行。
- 坐标以 0..1 的屏幕比例存储，执行时换算为像素。
- 支持点击、长按、折线/曲线滑动和多步骤顺序执行。
- 返回执行完成、取消或拒绝状态。

### FR-04 手势录制（M2）

- 快速模式：在透明画布中绘制一个手势。
- 连续模式：记录单次触摸，触摸结束后立即向目标页面复现，再记录下一步。
- 保存触点路径、持续时间、步骤间隔、方向和录制显示区域。
- 状态栏、导航栏及安全页面不承诺录制或执行。

### FR-05 编辑器（M2）

- 简单模式编辑名称、图标、速度、默认动作和重复次数。
- 高级模式以时间轴展示步骤。
- 支持拖动排序、复制、删除、插入等待和幽灵预览。

### FR-06 数据与历史（M2）

- 动作、设置和执行历史仅保存在本机。
- 不记录页面文字、截图、密码和用户输入内容。
- 执行历史仅包含动作 ID、时间、触发方式和结果。
- 提供 JSON 导入导出前必须进行格式校验与风险确认。

### FR-07 安全（M2）

- 执行中允许随时停止。
- 单个动作最长 60 秒，序列总时长默认不超过 5 分钟。
- 默认不在锁屏、权限确认、支付和已知敏感页面执行。
- 循环次数设置上限；第一版不提供无限循环。

## 5. 非功能需求

- 冷启动到首页可交互：中端设备目标小于 1.5 秒。
- 悬浮球点击到手势提交：目标小于 80 毫秒，不含多击判定窗口。
- 服务被系统回收后，不损坏动作数据。
- 支持 Android 8.0（API 26）到 Android 17；compileSdk/targetSdk 为 37。
- 支持简体中文；架构保留字符串国际化能力。
- 无网络权限；第一版离线运行。

## 6. 技术栈

| 层 | 选型 | 原因 |
|---|---|---|
| 语言 | Kotlin 2.3.21 | Android 主力语言、协程与密封模型适合动作引擎 |
| 构建 | AGP 9.4.0、Gradle 9.6、JDK 17 | 当前稳定组合，支持 API 37 与内置 Kotlin |
| UI | Jetpack Compose + Material 3 | 设置与编辑器状态驱动，便于后续时间轴 UI |
| 状态 | ViewModel + StateFlow | 页面单向数据流；M1 暂无复杂 ViewModel |
| 设置 | Preferences DataStore | 轻量、异步、适合悬浮球设置 |
| 动作数据 | Room 2.8.x（M2） | 事务、迁移、Flow 与执行历史查询 |
| 后台能力 | AccessibilityService | 手势派发、系统动作、可信覆盖层 |
| 悬浮 UI | TYPE_ACCESSIBILITY_OVERLAY | 不额外申请 SYSTEM_ALERT_WINDOW |
| 并发 | Kotlin Coroutines | 串行动作队列、延迟和取消 |
| 测试 | JUnit + Compose UI Test + instrumented tests | 覆盖动作缩放、多击判定和真机执行 |

不在第一阶段引入依赖注入框架。模块增多后再评估 Hilt，避免过早增加构建复杂度。

## 7. 架构

```text
Compose UI
   │
   ├── UserPreferences (DataStore)
   ├── ActionRepository (Room, M2)
   │
   └── AccessibilityService
          ├── BubbleController
          ├── TapSequenceClassifier
          ├── GesturePlayer
          └── PlaybackSession / StopController (M2)
```

领域对象只保存标准化坐标，不依赖 Android View。`GesturePlayer` 是唯一负责将领域动作转换为 `GestureDescription` 的边界类。

## 8. 数据模型（M2）

### ActionEntity

- `id: UUID`
- `name: String`
- `iconKey: String`
- `isDefault: Boolean`
- `createdAt / updatedAt: Instant`
- `recordedWidth / recordedHeight: Int`
- `orientation: PORTRAIT | LANDSCAPE | ANY`

### StepEntity

- `id: UUID`
- `actionId: UUID`
- `order: Int`
- `type: TAP | SWIPE | SYSTEM_ACTION | WAIT`
- `pathJson: String?`
- `durationMs: Long`
- `delayAfterMs: Long`

### ExecutionEntity

- `id: UUID`
- `actionId: UUID`
- `trigger: SINGLE_TAP | DOUBLE_TAP | TRIPLE_TAP | QUICK_RING | APP`
- `startedAt: Instant`
- `result: COMPLETED | CANCELLED | REJECTED | FAILED`

## 10. 验收测试

M1 验收条件：

1. 首次打开且服务未启用时，自动显示用途说明；暂不启用后，后续启动不重复弹出。
2. 从系统设置返回后，首页在无需重启的情况下显示已启用。
3. 悬浮球出现在其他普通 App 上方且可拖动。
4. 单击后约 280ms 执行一次从左向右的滑动。
5. 快速三击只执行一次最近动作，不额外执行单击动作。
6. 关闭悬浮球开关后覆盖层消失，重新开启后恢复。
7. App 未申请网络权限，服务配置禁止读取窗口内容。

## 11. 已知风险

- OEM 电池管理可能停止或禁用无障碍服务，需要品牌化指引与真机测试。
- 银行、支付和密码页面可隐藏覆盖层，这是预期安全行为。
- 分辨率、折叠屏、窗口模式和系统缩放会影响坐标，需要校准与测试矩阵。
- 多击判定会给单击增加少量延迟，应允许用户在“灵敏模式”和“多击模式”之间选择。
- Google Play 会审查 AccessibilityService 用途；实现和文案必须始终保持用户主动、确定性和透明。
